## 一 · tab 点不动：接线接在了错的编辑器上

不是 CSS 挡住，也不是事件冒泡——**监听器从来没有被绑上**。

| 位置 | 事实 |
|---|---|
| `super-admin.html:4732` | `editTenant()` 渲染出 `<nav class="editor-section-nav">` 和五个按钮 |
| `super-admin.html:4838` | `editTenant()` 调用 `openWorkspaceEditor()` 把它挂进 DOM |
| `super-admin.html:4725–4872` | **整个 `editTenant()` 里没有一次 `wireEditorSectionNav()`** |
| `super-admin.html:6574` | 唯一的调用点在 `addPlan()` 里——而套餐编辑器根本没有这条 tab 条 |

所以那行接线是空转的，tab 是五个没有任何监听器的 `<button>`。
手风琴还能用，因为 `<details>` 是浏览器原生的，不需要 JS。

### 三个做法

| | 做法 | 工作量 | 得到什么 | 代价 |
|---|---|---|---|---|
| **A** | 在 `editTenant()` 里补一行 `wireEditorSectionNav()` | 1 行 | 点击生效：展开对应折叠并滚过去 | 保留「tab 只是滚动锚点」这个四不像——既不是 tab 也不是手风琴，两套心智模型叠在一个表单上 |
| **B** | 换成真 tab：一次只显示一段，**复用文件里已有的 tab 组件** | 中 | 一个表单一种导航；少滚动 | 表单分页会**把校验错误和未保存的改动藏起来**——必须配套解决 |
| **C** | 删掉 tab 条，只留手风琴 | 小 | 诚实、可 Cmd-F、无 JS 依赖 | 五段全展开时很长 |

### 建议：B，但有前提

理由不是「tab 更高级」，而是**这个文件里已经有一套正规 tab 组件**（约 5480 行）：
`role="tab"` / `aria-controls` / `aria-selected`、roving tabindex、左右方向键切换，
用在租户详情面板上。编辑器不该是这个文件里的**第三种**导航模型。

改之前必须先解决 tab 隐藏内容带来的三件事：

1. **每个 tab 上要有错误计数**。右侧巡视栏已经在算「校验错误」，
   保存失败时要自动跳到第一个有错的 tab——否则错误藏在看不见的页里，
   用户只看到「保存失败」而找不到原因。
2. **每个 tab 上要有「已改动」圆点**。现在 dirty 状态只标在整个编辑器上
   （`workspaceEditorDirty`），分页之后必须能看出改动在哪一页。
3. **移动端**：tab 条已经是 `overflow-x:auto`，够用。

如果只想让今天点得动，先上 A（一行），B 单独排一轮。两者不冲突。

## 二 · i18n 门禁有个盲区，而且新代码一直在往里加东西

`test_admin_i18n_coverage.py` **确实覆盖** `super-admin.html`，而且是绿的。
但你截图里就有英文：「The studio's public address...」「Change public address」。

原因在门禁自己的第 32 行：

```python
OPAQUE_TAGS = {"script", "style", "code", "pre", "textarea"}
```

提取器扫的是**静态 HTML 文本节点**。而这个控制台的编辑器几乎全部由
`<script>` 里的模板字符串拼出来（`editTenant()` 一个函数就 148 行模板）。
门禁看不见那里，所以那里的英文永远不会被拦。

**量出来的规模**：`<script>` 里可见的界面文案 **98 条**，
其中 **11 条不在 `admin-i18n.js` 词典里**（正则跳过了带嵌套标签的长句，实际更多）。
其中四条是**今天我自己加的重置对话框**——盲区正在被持续填充。

两个修法：

- **B1（便宜）**：扩展提取器，让它也扫模板字符串里的标签文本。
  今天这段量化脚本就是雏形，落进测试即可。
- **B2（治本）**：把编辑器 markup 移进静态 `<template>` 元素，JS 只填数据。
  门禁自然看得见，顺带解决三、五两条。

建议先 B1（拦住出血），B2 排进结构性改造。

## 三 · 拼接出来的字符串，翻译不了

截图里的「额度 **Inherited from 工作室版**」是一条英文字面量拼上一个已翻译的套餐名。
词典按**整句**查表，拼接出来的句子永远查不到。

同类还有 `closeWorkspaceEditor()` 的 `window.confirm('Discard unsaved changes?')`
（`super-admin.html:3116`）——不但是英文，还用了浏览器原生对话框，
和控制台自己那套 `openModal()` 风格完全不一致。

## 四 · 一个文件里两套导航、两套对话框

- 导航：`.tab`（正规 tablist，详情面板用）与 `.editor-section-nav`（半成品，编辑器用）。
- 对话框：`openModal()`（控制台自己的）与 `window.confirm()`（原生）。

每多一套就多一个地方会漏掉 i18n、无障碍和键盘支持。第一条就是这么来的。

## 五 · 结构：7,210 行的单文件

`super-admin.html` 一个文件装下 markup + CSS + 全部 JS，所有编辑器都是模板字符串。
一、二、四三条的**共同成因**就是这个。

不建议现在大改——但每加一个编辑器，这三类问题就会再复制一份。
最小的止血是 B2（把 markup 移进 `<template>`），它不需要拆文件。
