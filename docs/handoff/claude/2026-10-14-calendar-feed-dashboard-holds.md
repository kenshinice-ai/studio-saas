### 日历订阅源（`103c539`）

- token 查找改走函数 `calendar_subscription_tenant(token_hash)`。它只返回租户 ID，查完再绑定租户。表本身仍强制 RLS，没有豁免。
- 课表改用 `scheduling.occurrences()`。周几错位、补课缺失、暂停窗口误用三处一起消失。
- 发放订阅要 `students:write`（以前是 `students:read`）。列表可以按学员过滤。
- 后台入口：学员档案 → 专区 → 家庭日历订阅。链接只显示一次，可复制，可停用。

### 工作台例外清单（`2e64c5b`）

- 一张清单，按顺序：等回复的报名和约课 → 未付清发票 → 课时 ≤ 2 → 长期没来 → 14 天内到期的补课额度 → 过了周期没写的成长报告 → 生日。
- 新的两行读 `/scheduling/credits` 和 `/progress-reports/overdue`。没有权限的角色拿到 403，这一行不出现。
- 「长期没来」沿用设置里的天数（默认 90）。「排了课连续缺席」的口径没定，没有做。
- 顺手修了：应收那一行的图标名 `invoice` 不存在，一直没有图标。

### 约课保留名额（`73dc4a4`）

- 提交时有空位，就保留到 `hold_expires_at`。满了照样收申请，但不保留。
- 同一个电话在一个租户里同时只保留一个位置。
- 公开课表、提交、审批共用 `services/booking_holds.py` 的同一个计数式，并先锁班次行。
- 审批时算别人的保留，不算自己的。
- 回执只说租户设的保留时长，不说这条申请有没有拿到保留。原因：否则可以拿电话号码探测「这个号码在这里有没有申请」。
- 后台：系统设置 → 运营默认，可选不保留 / 24 / 48 / 72 小时（接口接受 0–168）。待处理列表显示「名额保留到 …」或「名额保留已到期」。
- `manual.html` 里「申请不会占位」那段已改。旧设计文档 §3.1 标为被取代。
