# PWE Studio v10.2.1 — 设置页版面修复

> v10.2.0 把系统设置从 `fixed` 覆盖层改成正常页面，**但没有把它在 DOM 里挪
> 位置**。它原本挂在 `<main>` 外面 —— 覆盖层靠视口定位，挂哪都对；改成正常流
> 之后，它就渲染在主内容列之外了：设置内容跑到侧栏左边，主列只剩一个页脚。
>
> **我上一版是怎么漏掉的**：用 JS 查了标签数、可见面板数、`aria-selected`、
> URL 往返、后退键，全部通过 —— 元素都是对的，位置是错的。**查 DOM 属性
> 查不出版面。** 这次量了坐标：主列从 240px 起（侧栏之后），面板在 264px、
> 宽 1148，`main.contains(panel)` 为真，无横向溢出。
>
> 加了一条结构守卫：`{showSettings && (` 必须落在 `<main …>` 与 `</main>`
> 之间。已验证它在修复前的代码上会失败。
>
> **已上线** 2026-08-14。`appVersion=10.2.1`，无迁移。线上没有操作账号，
> 登录后的版面在生产上量不到；能做的最强验证是：线上供给的 bundle 与我在
> 浏览器里量过的那份本地产物**逐字节相同**。
>
> 教训写在这里，因为它会再犯：**查 DOM 属性查不出版面**。元素数量、
> `aria-selected`、URL 往返全绿，位置照样可以是错的。改动了「东西画在哪儿」
> 的时候，必须看那一页。
