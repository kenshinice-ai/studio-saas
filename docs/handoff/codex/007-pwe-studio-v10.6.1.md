# PWE Studio v10.6.1 — 共享模块，因为聪明的委托会静默失败

> v10.6.0 修了可信代理，**但没有生效**。部署后在生产上验了一次：仍然是
> `172.18.0.1`。
>
> 原因是我在 `api_v1._client_ip()` 里写了 `from server import _is_trusted_proxy`。
> `server.py` 是入口，运行时它的模块名是 `__main__`，这个 import 解析不到正在
> 跑的那个模块；而我给它套了 `except Exception` 兜底，于是它**静默退回**到
> 旧的「只信任 127.0.0.1」规则。测试全绿，部署全绿，行为没变。
>
> 判断逻辑移到 `studiosaas/netaddr.py`，两边都 import 它。共享模块不会这样失败。
>
> **教训**：跨模块借一个函数，看起来省事，实际上是把「两处会漂」换成了
> 「一处会静默断」。而我给它加的 except 正好保证了断掉时没人知道。
> 修完一定要**回到线上量一次**——这一条如果不是回去查了审计表，会一直是绿的假象。
