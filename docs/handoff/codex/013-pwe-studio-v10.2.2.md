# PWE Studio v10.2.2 — 页脚归位

> v10.2.1 把设置块搬进了 `<main>`，但搬到了页脚**后面**，于是
> 「© 2026 …」印在了标签条和设置内容中间。
>
> 修法不是再搬设置块，而是搬页脚：**页脚本来就该是内容列的最后一样东西**。
> 设置还是覆盖层的时候看不出这个顺序问题；它变成正常页面之后才暴露。
>
> 中途试过搬设置块，边界匹配错了，把页脚包进了设置块内部（`footerInsideSettings`
> 为真）。回退重做，没有在坏结构上叠补丁。
>
> 这一版和上一版是同一个形状的 bug：**元素在源码里的位置，在绝对定位时无关
> 紧要，在正常流里就是它在屏幕上的位置。** 两次都不是 DOM 查询能发现的。
