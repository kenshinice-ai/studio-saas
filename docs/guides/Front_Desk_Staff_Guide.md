# CMS 前台与通用员工手册 · Front Desk / Staff

> 适用版本：PWE Studio v9.8.2 · 界面：运营 CMS（`/<工作室网址标识>/cms`）
> 其他角色手册见 [手册总览](README.md)

## 角色定位

本手册覆盖两个 CMS 角色：

- **Front Desk（前台）**：负责接待相关的一切——报名审批与线索跟进、学员
  建档与资料维护、课时充值、查看公开课表约课请求、发放学员专区访问码。
  前台**不做签到**（课程安排标签页不会出现）、不管理作品集、看不到任何
  财务报表。
- **Staff（legacy 通用员工）**：早期的「全能员工」角色，能力接近 Manager：
  建档、签到、充值、审批、作品集都能做，但**没有**退款、经营统计、数据
  导出和作品分享链接。新建团队成员时建议优先用 Front Desk / Teacher /
  Manager 等职责更清晰的角色。

两个角色不是简单的上下级：**Staff 比前台多签到（课程安排）和作品集；
Front Desk 独有 `class_bookings:review` 约课审核权限**。当前 CMS 已把这项
权限落实为「待处理 → 约课」卡片上的批准/婉拒按钮；前台仍不能修改课程、容量
或上课时间。旧版说明中的「前台 CMS 按钮待独立任务」仅作为迁移记录保留。

登录后，顶部通知会提示新的报名；Front Desk 还会看到自己有权限审核的约课通知。通知每 30 秒刷新一次，点击后进入「待处理」对应标签；已读状态按账号分别保存。

## 快速上手

1. 打开 `https://<你的域名>/<工作室网址标识>/cms`，输入 Owner 发给你的
   「管理员邮箱」和临时密码，点「进入系统 →」。
2. 第一次登录后，点侧栏齿轮打开「系统设置」，在「修改登录密码」里把临时
   密码换成自己的密码（新密码至少 8 位）。
3. 你的导航标签页：
   - **Front Desk**：工作台 · 待处理 · 学员 · 充值与退款 · 操作日志;
   - **Staff**：工作台 · 待处理 · 课程安排 · 课程 · 学员 · 作品 · 充值与退款 · 操作日志
     （即完整导航去掉「经营统计」）。
4. 工作台的「经营真账」折叠区对你只显示上课人次；已赚收入、预收负债等
   财务字段不会下发到你的账号——这是后端按角色投影的，不只是界面上藏起来。

> 登录提示「该账号没有有效的工作人员身份，请联系管理员」= 你的成员身份
> 被停用了，找 Owner 在系统设置里重新启用。

## 一、报名审批（待审核）——前台的主战场

家长在门户或快速报名页提交后，申请进入「待审核」标签页（导航上有红色
数字角标）。每条申请卡片显示：

- 姓名、电话/微信/邮箱、生日、留言;
- **提交时间**：格式为 `YYYY-MM-DD HH:mm`（如 `2026-07-27 14:30`）;
- **来源**：门户网站 / 快速报名;
- **状态**：以中文显示——待审核 / 已联系 / 已约试听 / 跟进中 / 已批准 /
  已建档 / 已拒绝 / 重复申请 / 已流失 / 已归档（英文界面下自动翻译）。

### 「疑似重复」角标

如果两条**待审核申请使用相同的手机号**（同一家长提交了两次，或家长和
学员填了同一个号码），两张卡片都会带上琥珀色的「疑似重复」角标。

**处理原则：先核实，再批准。** 看到角标时不要直接双双批准——那会建出两份
学员档案，后续课时账会乱。正确做法：

1. 联系家长确认是重复提交还是两个不同的孩子;
2. 重复提交 → 保留信息最全的一条批准，另一条点「拒绝」;
3. 两个孩子共用家长手机号 → 属于正常情况，分别批准即可。

此外，如果申请的电话与**已建档学员**重复，卡片会另外提示「此电话已有
学员」——同样先核实再操作。

### 跟进与批准

1. **跟进**：设置「下次跟进」日期，或点「已联系」「已约试听」「继续跟进」
   更新线索状态；到期跟进会出现在工作台「今日待办」。
2. **批准**：在「初始课时数」填入数字（可为 0），点「批准建档」——系统
   自动创建学员档案并按填写的课时入账。
3. **拒绝**：点「拒绝」，该申请不再显示。

### 公开课表约课请求：当前边界

「待处理」里的「约课」子标签与普通报名不是同一种记录：已有学员批准后会
加入对应日期的名单；新访客批准后才进入报名线索。当前 CMS 已显示
Front Desk 的 `class_bookings:review` 批准/婉拒按钮；无论何时，前台都不能修改
课程、容量或上课时间。

## 二、学员建档与资料维护

- 「➕ 新建」建档：姓名、联系方式、生日、初始课时，可上传头像照片。
- 打开学员档案可编辑资料、调整备注标签、查看课时余额与最近流水、归档学员。
- 「CSV」导出按钮你**看不到**——数据导出仅 Owner/Manager。
- 作品集区块：Staff 可上传/编辑/删除作品（JPEG / PNG / WebP，单张
  ≤ 3000 万像素）；**Front Desk 连作品都看不到**——不是"不能编辑"，是后端
  不给前台 `portfolio:read`，整个区块不会出现。家长问作品的事请转给
  老师或店长。

## 三、学员专区访问码（前台可以发）

家长自助查询用「姓名 + 手机号 + 6 位访问码」。访问码在学员档案的
「学员专区」区块管理，**Front Desk 和 Staff 都可以操作**（属于学员资料
维护权限）：

1. 学员必须先有手机号码——没有会提示「请先补充学员手机号码，再生成访问码」。
2. 点「生成访问码」。**明文只显示这一次**，复制后当面或私信交给家长；
   系统不保存明文。
3. 家长忘码 → 「更换访问码」立即作废旧码并踢掉已登录会话，把新码发给家长。
4. 「停用」完全关闭该学员的自助查询。

## 四、充值结算

1. 「选择学员」搜索并选中——先核对头像、当前余额和最近 3 笔流水。
2. 点「套餐快选」自动填入课时数和金额，或手动填「课时数」「实收金额 (AUD)」。
3. 选付款方式（现金 / 微信 / 银行转账 / 其他），备注选填。
4. 点「确认收款并入账」，成功后可一键复制发给家长的确认话术。

**你的页面上没有「退款退课」按钮**——退款需要 `credits:refund` 权限，
仅 Owner/Manager。家长要求退款时：登记诉求，转给店长或 Owner 处理。

## 五、课程安排与签到（仅 Staff）

Staff 拥有「课程安排」标签页，签到流程与 [Teacher 手册](Teacher_Guide.md)
第二节相同：选日期 → 当日名单签到（自动扣课时入账）→ 签错可撤销（课时
退回、账本留冲正流水）。每周课表的班次「新增/编辑/删除」仍是
Owner/Manager 专属。Front Desk 没有这个标签页。

## 六、操作日志

你的每笔充值、审批、建档（Staff 还有签到）都会留痕，可在「操作日志」
标签页按学员、类型、日期筛选查看。v8.2.3 起 30 类操作全部有中文名称与
可读摘要（例如「新生建档」「生成家长访问码」「加入排课 · 3 人」），
不再出现机器编号；记录保留两年。「导出 CSV」按钮仅 Owner/Manager 可见。
Owner 还能在 Studio Admin 的「数据分析 → 操作审计」里复核全店操作——
按规程办事，日志是你的保护。

## 常见问题（FAQ）

**Q1：登录提示「该账号没有有效的工作人员身份，请联系管理员」？**
你的成员身份被 Owner 停用了（或从未开通）。请 Owner 在 CMS 系统设置 →
团队与权限里启用你的账号。密码错误则会提示邮箱或密码不正确，注意区分。

**Q2：为什么我看不到「退款退课」按钮？**
退款需要 `credits:refund` 权限，仅 Owner/Manager。这不是故障，是权限
边界。家长的退款诉求请转给店长/Owner。

**Q3：为什么没有「经营统计」标签页？**
经营统计需要 `analytics:read` 权限（Owner/Manager）。你的工作台也只显示
上课人次，不显示营收等财务字段。

**Q4（Front Desk）：为什么我没有「课程安排」？**
前台角色没有签到权限（attendance:write）。签到由 Teacher/Staff/Manager
完成；你负责的是报名、建档、充值和访问码。

**Q5：「疑似重复」角标是什么意思？**
另有一条待审核申请使用了相同手机号。先联系家长核实是重复提交还是二孩
共用号码，再决定批准哪条——直接全批会造成重复学员档案。

**Q6：家长问作品「分享链接」，我能生成吗？**
不能。对外分享链接的**创建**是 Owner/Manager 专属（portfolio:share）。
Staff 可以在作品集里**撤销**已有的链接（撤销属于作品维护权限）；
Front Desk 两者都不行。家长需要分享链接时转给店长。

**Q7：家长说想「登录系统」看孩子情况？**
家长不能登录 CMS（家长账号会被拒绝：「家庭自助登录暂未开放，请联系
工作室」）。请给家长发访问码，引导用官网「学员专区」自助查询——这正是
前台的职责，见上文第三节。

**Q8：界面语言怎么切换？**
右上角「中文 / English」按钮，整个浏览器记忆一份（与 Studio Admin 共用），
默认中文。注意：学员姓名、课程名、作品标题等运营数据按录入原样显示，
不随界面语言翻译。

## 权限边界表

| 功能 | Front Desk | Staff | 说明 |
|---|---|---|---|
| 工作台（无财务字段） | ✅ | ✅ | 仅显示上课人次 |
| 报名审批（待审核） | ✅ | ✅ | registrations:write |
| 约课请求批准 / 婉拒 | ✅（后端） | ❌ | class_bookings:review；前台 CMS 按钮待独立任务 |
| 学员建档 / 编辑 / 归档 | ✅ | ✅ | students:write |
| 学员专区访问码（生成/更换/停用） | ✅ | ✅ | 属学员资料维护 |
| 充值 | ✅ | ✅ | credits:write |
| 退款退课 | ❌ | ❌ | credits:refund，仅 Owner/Manager |
| 课程安排 / 签到 / 撤销 | ❌ | ✅ | attendance:write，前台没有 |
| 作品集查看 | ❌ | ✅ | portfolio:read，**前台没有** |
| 作品集上传 / 编辑 / 删除 | ❌ | ✅ | portfolio:write |
| 作品分享链接创建 | ❌ | ❌ | portfolio:share，仅 Owner/Manager |
| 作品分享链接撤销 | ❌ | ✅ | 撤销走 portfolio:write |
| 经营统计 / 财务报表 | ❌ | ❌ | analytics:read，仅 Owner/Manager |
| 数据导出（CSV） | ❌ | ❌ | data:export，仅 Owner/Manager |
| 团队管理 / 品牌与官网 | ❌ | ❌ | Owner 专属 |
| 修改自己的密码、退出登录 | ✅ | ✅ | 系统设置 |

角色权限的完整对照见 [手册总览](README.md) 的权限矩阵与
[Admin_Guide](../Admin_Guide.md) 的 Roles & Permission Matrix。
