# CMS 运营手册 · Manager（店长/运营主管）

> 适用版本：PWE Studio v9.2.0 · 界面：运营 CMS（`/<工作室网址标识>/cms`）
> 其他角色手册见 [手册总览](README.md)

## 角色定位

Manager 是工作室的日常运营负责人：学员档案、课程安排与签到、课时充值与退款、报名审批、经营统计，这些都在你的权限范围内。你与 Owner 的差别只在两处——**你不能管理团队成员账号**（只能查看成员列表），**也不能进入 Studio Admin 修改品牌、配色和门户内容**（那些属于 Owner）。

### 通知铃铛（v9.2.0）

CMS 右上角的铃铛会显示新的报名和约课申请。系统每 30 秒检查一次，浏览器重新回到前台时也会立即检查；有新事项时会弹出提示。点击通知可直接进入「待审核」对应标签，处理后可单条标记已读，也可以选择「全部已读」。通知历史按用户分别记录，不依赖 Gmail、短信或浏览器推送。

## 快速上手

1. 打开浏览器访问 `https://<你的域名>/<工作室网址标识>/cms`。
2. 在登录页输入「管理员邮箱」和「密码」，点击「进入系统 →」。
3. 登录后默认进入「工作台」。左侧（手机上是底部）导航依次是：
   **工作台 · 课程安排 · 学员档案 · 待审核 · 充值结算 · 操作日志 · 经营统计**。
4. 右上角（侧栏底部）的齿轮图标打开「系统设置」弹窗——修改密码、退出登录、
   充值套餐、未到访预警天数、团队成员列表都在这里。

> 登录提示：如果看到「该账号没有有效的工作人员身份，请联系管理员」，说明你的
> 成员身份被停用了，找 Owner 在系统设置里重新启用。

## 一、工作台（dashboard）

工作台是每天开工的第一屏：

- **今日指挥台**：应到 / 已签到 / 待审核 / 低课时四个数字，下面四个快捷按钮
  「今日排课」「➕ 新建学员」「审核报名」「充值结算」直接跳转对应页面。
- **四个统计卡**：学员总数、全部剩余课时、今日排课、历史总营收。点卡片会带着
  相应筛选跳到对应标签页。
- **经营真账（估算）**：可展开的折叠区，显示已上课人次、已赚收入（估）、
  预收未耗（负债）、净现金收入。这一区依赖财务权限（`analytics:read`），
  Manager 和 Owner 都能看到；Teacher / Front Desk 只会看到上课人次。
- **今日待办**：自动汇总课时清零、仅剩 1 课时、流失风险、本周/本月生日、
  到期跟进的报名线索。
- **课时预警**：余额 ≤ 2 课时的学员列表；**长期未到访**：有余额但超过设定
  天数没来上课的学员（天数在系统设置里可选 60/90/120/180 天）。

## 二、课程安排与签到（roster）

1. 点导航「课程安排」。顶部可切换日期（默认今天）。
2. **每周课表**：固定班次按周几自动排入当日名单。点「➕ 新增班次」填写
   班次名称、周几、开始时间、时长、容量，并勾选学员；保存后每周该日
   自动出现在当日排课里。班次的「编辑」「删除」按钮只有 Owner/Manager 可见。
   「固定课表 ICS」只导出周期班次且不含学员姓名；没有固定班次时按钮会禁用。

   **v8.8.0 新增的四项（都是选填）**：

   - **关联课程**：选了课程，公开课表就能用课程的简介和适龄段；不选只用
     班次名称，功能不受影响。
   - **授课老师**：指定后，同一位老师在同时段被排到两处会提示冲突。
     没指定老师的班次沿用旧提示（只比时间）。
   - **地点 / 教室**。
   - **「在公开课表上展示这个班次」**：**默认不展示**。一对一时段、内部
     补课、留给特定家庭的试听位不应该出现在公网上，所以是逐条勾选，不是
     一键全开。班次卡片上会直接写「● 已公开」或「○ 仅内部可见」，
     不用打开编辑器逐个确认。

   > 老师姓名要不要出现在公开课表上，由**「设置 → 团队与权限」里那位老师
   > 自己的开关**决定，不是这里。没开时课表照常展示，只是不带老师姓名 ——
   > 勾选公开时编辑器会当场提示这一点。

   > **课程在哪里建？**「设置 → 课程管理」（v8.10.3 新增）。排课编辑器的
   > 「关联课程」下拉旁边有直达链接。课程是可选的：不关联也能正常排课，
   > 只是公开课表上只有班次名称，没有简介和适龄段。
   > 移除课程是**归档**不是删除——已经关联它的班次、已经按它记过的账都还
   > 在引用它，界面会告诉你目前有几个班次正在用。

   **停课**：班次卡片上的「停课」按钮用来说「这个周三不上」。日期默认已填
   好下一次上课日，可以写原因（如「公众假期」），原因会显示给家长。已停课
   的日期列在卡片上，点「恢复」撤销。日期必须落在这个班次实际上课的那一天，
   否则会被拒绝 —— 写错周几的停课会被存下来却不生效，拒绝是唯一能让你当场
   发现的方式。
3. **当日名单**：固定班次学员自动进入名单，也可以手动把学员加入当天。
   选定日期的名单有学员后，「导出当日 ICS」才会出现；它是包含学员姓名的
   私人运营文件，与上方固定课表导出不是同一个文件。
4. **默认时间**：Owner/Manager 可在「设置 → 课程安排默认时间」修改。默认
   为 14:30，供新的手动排课、班组模板和新固定班次使用；修改不会改动已经
   保存的上课时间。
5. **签到**：在名单里为到场学员签到，每次签到扣减相应课时并记入账本；
   支持批量签到（已签到过或余额为 0 的学员会被自动跳过并提示）。
6. **撤销**：签错了可以撤销当日签到，课时会退回，考勤标记为已作废（reversed），
   账本留下对应的冲正流水——历史不会被抹掉。
7. **生日提醒**：近 14 天内生日的学员会显示横幅，点学员名片一键复制生日
   祝福话术（话术自动带上学员名和工作室名）。

## 三、学员档案（students）

- **搜索与筛选**:顶部搜索框支持姓名 / 电话 / 微信 / 邮箱；筛选按钮有
  全部、有余额、低余额、已清零、归档库、活跃、低频、流失风险；排序支持
  按姓名、课时余额、最近活跃。
- **新建学员**：点「➕ 新建」（即「新建学员」标签页），填写姓名、联系方式、
  生日、初始课时等信息，可上传头像照片。
- **学员详情**：点某个学员打开档案，可以：
  - 编辑资料、调整备注和标签;
  - 查看课时余额与最近流水;
  - 管理**作品集**：上传作品照片（可填标题、日期、说明），编辑或删除。
    格式限 JPEG / PNG / WebP，**单张最大 3000 万像素**（约 6000×5000），
    超限会明确拒绝；
    作品标题是运营数据，**只存单语、不随界面语言翻译**（产品决策，见
    `docs/Glossary.md`）;
  - 作品「公开到门户作品墙」需要学员/家长的**公开授权**（publication consent）
    有效；授权撤回后所有作品自动转为私人可见;
  - 生成**对外分享链接**（portfolio:share，仅 Owner/Manager）：一个免登录
    的临时作品展示页，有效期可选 **1–90 天**（默认 30 天），原始链接只
    显示一次，发给家长/亲友即可。已有链接可随时**撤销**（撤销放宽到所有
    能编辑作品集的角色）；到期自动失效。每次创建都写入操作日志与审计;
  - 管理**学员专区访问码**（见下文第六节）;
  - 归档学员（可从「归档库」筛选里找回）；「彻底删除档案」是不可逆操作，
    会要求确认。
- **批量操作**：勾选多个学员后，可以批量复制续课提醒话术、批量归档。
- **CSV 导出**：「CSV」按钮导出学员档案（Owner/Manager 可用）。

## 四、报名审批（pending 待审核）

> **v8.10.0 起这一页有两个标签：「新报名」和「约课」。**
> 导航角标是两者之和——它回答的是「有没有事等我处理」这一个问题。
> 但两个数字在页面上分开写，因为它们含义不同：新报名批准后**建学员**，
> 约课批准后**占座位**。把后者算进前者，会让「本月新报名」永远虚高。

### 4b. 约课申请（需要 Owner 在 Studio Admin 打开公开课表与约课）

家长在公开课表页填**学员全名 + 手机号**即可申请，不需要注册账号。每条显示：

- 家长填的姓名与手机号、想上的那一节课（日期 · 时间 · 课程名）、备注;
- **「已是学员」或「新访客」角标**——系统按姓名+手机号比对现有学员，
  规则与「学员专区」查余额那一条完全相同（单字名只匹配名、明确排除只用
  姓氏、必须唯一命中）。
  > 这个判断**只在这里显示**。公开表单给家长的回应，无论是否命中，
  > 内容完全一样——否则那个表单就成了「这个号码是不是你们的学员」的
  > 查询接口。
- **当前余位**（不是提交时的余位）。

**批准**：
- 已是学员 → 直接排入那一天的名单（来源记为「约课」），不计入新报名;
- 新访客 → 同时建一条待审核报名，走上面 4 的流程。

**满了怎么办**：容量在按下「批准」那一刻才复核。如果这节课已经满了，
批准会被拒绝并提示——先提高班次容量，或婉拒并联系家长改约。
待确认的申请**不占座位**，所以一个没人看过的申请不会挡住真会来的家庭。

### 4a. 新报名

家长在门户或报名页提交后，申请出现在「新报名」标签里：

1. 每条申请显示姓名、电话/微信/邮箱、生日、留言、提交时间（格式
   `YYYY-MM-DD HH:mm`）、来源（门户网站 / 快速报名）和中文状态标签
   （待审核 / 已联系 / 已约试听 / 跟进中 / 已批准 / 已建档 / 已拒绝 /
   重复申请 / 已流失 / 已归档）。如果电话与现有学员重复，会提示
   「此电话已有学员」；如果**两条待审核申请共用同一手机号**，两张卡片
   都会带琥珀色「疑似重复」角标——先联系家长核实（重复提交还是二孩共用
   号码）再批准，避免建出重复学员档案。
2. **跟进**：可设置「下次跟进」日期，或点「已联系」「已约试听」「继续跟进」
   更新线索状态；到期的跟进会出现在工作台「今日待办」。
3. **批准**：在「初始课时数」填入数字（可为 0），点「批准建档」——系统自动
   创建学员档案并按填写的课时入账。
4. **拒绝**：点「拒绝」，该申请不再显示。

## 五、充值结算（topup）

页面顶部有两个模式按钮：「充值」和「退款退课」（退款按钮只有 Owner/Manager
能看到）。

**充值：**
1. 「选择学员」搜索并选中学员——会显示头像、当前余额和最近 3 笔充值/退款
   流水，动手前先核对。
2. 点「套餐快选」中的某个套餐自动填入课时数和金额，也可手动填「课时数」
   「实收金额 (AUD)」。
3. 选付款方式（现金 / 微信 / 银行转账 / 其他），备注选填。
4. 点「确认收款并入账」。成功后可一键复制发给家长的确认话术。

**退款退课（需要 `credits:refund` 权限，仅 Owner/Manager）：**
1. 切换到「退款退课」模式（红色）。
2. 填「退课节数」「退款金额 (AUD)」「退款方式」和**必填的退款原因**。
3. 点「确认退款退课」，界面会先弹确认框列出退课后的余额变化。
4. 退款金额以负数计入营收（净额自动核减），退课节数直接从余额扣减，
   全程记入账本与操作日志。成功后可复制「退款确认」话术发给家长。

> 其他角色点退款会提示「当前角色无退款权限」。

## 六、学员专区访问码

学员/家长不是用账号密码登录，而是用**姓名 + 手机号 + 6 位访问码**在门户
「学员专区」自助查询课时余额、下次上课、签到记录和作品。访问码由店员在
CMS 里生成后**当面或私信交给家长**：

1. 打开学员档案，找到「学员专区」区块。
2. 学员必须先有手机号码——没有会提示「请先补充学员手机号码，再生成访问码」。
3. 点「生成访问码」。**明文只显示这一次**，点复制按钮发给家长；系统不保存
   明文，只存哈希。
4. 「更换访问码」会立即作废旧码并踢掉已登录的会话；「停用」则完全关闭该
   学员的自助查询。

## 七、操作日志（logs）

所有充值、签到、退款、档案变更都会留痕。支持按学员、按操作类型、按日期
范围筛选，分页 30 条一页。Owner/Manager 可导出 CSV。

**v8.2.3 补全了这一页。** 在此之前日志只显示签到与课时变动——归档、改名、
排课、作品集编辑虽然都执行了，却从来没有列出来过；少数能显示的行还带着
机器格式的元数据，长成 `Core opening balance import source:c318f4e42f05
student:1783863014768` 这样。现在覆盖 30 类操作，每类有中文名称和一句
可读摘要：

| 分类 | 记录的动作 |
|---|---|
| 学员 | 新生建档 · 更新档案 · 归档学员 |
| 排课 | 加入排课 · 取消排课 · 恢复排课 · 调整排课 · 新增/修改/删除班次 |
| 作品 | 上传作品 · 修改作品 · 删除作品 · 生成分享链接 · 撤销分享链接 |
| 报名 | 收到注册申请 |
| 家长访问 | 生成家长访问码 · 撤销家长访问码 · 解锁家长访问 |
| 课程与课包 | 新增/修改/归档课程 · 新增/修改/下架课包 |
| 其他 | 导出数据 · 发布网站 · 新增或更新成员 · 调整成员权限 · 修改默认上课时间 |

摘要按动作类型给出人看得懂的内容：排课显示日期、时间和人数（多人时带
「· N 人」，一对一带「· 1 对 1」），导出显示类型和行数，班次显示班次名。

> **保留期限**：审计记录保留 **两年**，之后自动清理（v8.2.12 起按月执行）。
> 需要更长的留存请自行定期导出 CSV。

## 八、经营统计（stats）

顶部四个总量卡：历史总营收、建档学员、累计消课、课时资产池。下方有：

- 近 12 个月营收 / 消课柱状图；
- 经营月报（近 6 个月）；
- **财务明细报表**：按月度/年度/自定义区间筛选，可按学员过滤；
- 单个学员的消费分析。

此标签页需要 `analytics:read` 权限——Teacher / Front Desk / Staff 的导航里
没有它。

点侧栏齿轮打开「系统设置」：

## 常见问题（FAQ)

**Q1：为什么我看不到「退款退课」按钮？**
退款需要 `credits:refund` 权限，只开放给 Owner 和 Manager。如果你是 Manager
仍看不到，请确认登录的账号角色。

**Q2：签到签错人了怎么办？**
在当日排课名单里撤销该学员的签到即可，课时自动退回，账本会记一笔冲正流水。

**Q3：访问码忘了/家长说登录不上？**
明文只在生成时显示一次，无法找回。打开学员档案点「更换访问码」生成新码
发给家长即可（旧码立即失效）。连续输错会触发临时锁定，等提示的等待时间
过后再试。

**Q4：为什么修改不了门户网站上的介绍和配色？**
门户内容、品牌、配色、报名表字段都在 Studio Admin，属于 Owner 权限边界。
需要修改时联系 Owner。

**Q5：待审核里同一个家长交了两次怎么办？**
两条待审申请共用同一手机号时都会带「疑似重复」角标；与已建档学员同号
则提示「此电话已有学员」。先联系家长核实——重复提交就保留信息最全的
一条批准、拒绝另一条；两个孩子共用家长号码则分别批准。

**Q6：课程名想同时显示中英文，怎么填？**
不支持也不需要——课程名、作品标题是运营数据，按录入原样显示、不随界面
语言翻译，这是明确的产品决策（见 `docs/Glossary.md`）。

**Q7：保存时提示数据冲突/版本过期？**
说明另一台设备（或另一位同事）刚保存过。刷新页面拿到最新数据后再改一遍，
避免互相覆盖。

**Q8：家长说想用邮箱密码「登录系统」？**
家长不能登录 CMS——家长账号登录会被拒绝：「家庭自助登录暂未开放，请联系
工作室」。给家长发学员专区访问码（见第六节），家庭自助查询走官网
「学员专区」。

**Q9：作品分享链接怎么开、多久有效？**
学员档案的作品集区块 → 生成分享链接，选有效期 1–90 天（默认 30 天）。
原始链接只显示一次，复制后发出。要提前作废就点撤销；到期自动失效。
创建仅 Owner/Manager；每次创建 Owner 都能在审计里看到。

**Q9b：作品/头像传不上去？**
先看格式（JPEG / PNG / WebP）和尺寸（单张 ≤ 3000 万像素）。如果是 v8.2.6
之前的版本，那不是你的问题——当时生产环境的所有图片上传都会失败，v8.2.6
已修复。

**Q10：数据导出谁能用？**
学员 CSV（学员档案页「CSV」按钮）和操作日志 CSV 都需要 data:export
权限，仅 Owner/Manager。每次导出会记入审计（`data.exported`）。另外
导出功能受套餐开关约束，套餐未开通时会提示联系平台方。

**Q11：Owner 说在「操作审计」里看到我的操作？**
是的。Owner 在 Studio Admin「数据分析」有一个操作审计面板，可复核全店
的退款、导出、分享链接等敏感操作（Manager 无法查看该面板）。正常按规程
操作即可，日志同样是你的凭证。
