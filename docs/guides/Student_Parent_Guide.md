# 学员与家长手册（门户 · 报名 · 自助查询）

> 适用版本：PWE Studio v8.10.1 · 界面：工作室官网门户（`/<工作室网址标识>`）与
> 独立报名页（`/<工作室网址标识>/register`）
> 其他角色手册见 [手册总览](README.md)

## 你是谁、你能做什么

你是学员本人或家长。你**不需要注册账号、不需要密码**：

- 在工作室官网浏览课程、老师介绍、学员作品和常见问题;
- 在线填写报名/预约体验表;
- 用工作室发给你的 **6 位访问码**，在「学员专区」自助查询课时余额、下次
  上课时间、上课记录和孩子的作品。

> 注意：家长身份**不能登录**工作室的内部管理系统（CMS）。如果你尝试用
> 邮箱密码登录 CMS，会看到「家庭自助登录暂未开放，请联系工作室」。
> 家庭自助查询请使用下文的「学员专区」访问码方式。

## 一、浏览官网

官网是一个单页站点，顶部导航依次是：**主理人 · 课程 · 学员作品 · 常见问题 ·
学员专区 · 预约体验**（手机上点右上角菜单按钮展开同样的链接）。

页面从上到下可能包含：首屏介绍、工作室简介（带轮播图）、主理人介绍、课程
与班型卡片（每张卡片有「报名 →」按钮）、学员作品墙（点开可放大浏览，
支持左右切换）、学员专区引导、常见问题折叠列表、联系我们（地址/邮箱/电话）。
工作室没有填写的板块会自动隐藏，所以不同工作室看到的板块可能不同。

页脚有「隐私说明」链接，报名前建议阅读——它说明了收集哪些信息、用途、
照片与作品的展示规则、以及你的权利。

### 切换语言（中 / EN）

导航栏右侧（手机菜单底部）有「中 / EN」切换按钮：

- 点击后界面文字立即切换，你的选择会记住在这台设备上（每个工作室独立记忆）;
- 首次访问时按浏览器语言自动选择；也可以用网址参数 `?lang=en` 直接分享
  英文版页面;
- **课程名称、作品标题、地址、电话等原始信息不会翻译**——它们按工作室
  录入的原文显示，这是有意的设计;
- 如果你正在「学员专区」查看结果，切换语言会退出结果页，需要重新查询。

## 一之二、公开课表与约课（v8.9.0 / v8.10.0，需工作室开启）

如果工作室开了这个功能，官网导航会出现**「课程安排」**，点进去是一个独立
页面（网址形如 `.../timetable`，可以直接转发给家人）。

- 按**日期**分组显示接下来一到四周的公开课程，工作室决定展示几周;
- 每节课显示时间、课程名，工作室还可以选择显示老师、地点、适龄段、
  结束时间、剩余位置;
- **剩余位置用文字加颜色**：「还有 N 位」（绿）/「快满了 · 还有 N 位」
  （琥珀）/「已满 · 可加候补」（灰）。**颜色只是第二重提示，文字永远在**，
  所以色觉障碍、黑白打印或深色模式下都读得出来;
- **停课的那一天会被划掉并写明原因**（如「公众假期」），而不是消失——
  所以你看到的课表就是当天真实会发生的事;
- 时间以**工作室所在时区**为准，页面底部会写明是哪个时区。人在国外看也
  不会差一天。

**约课不需要注册。** 如果工作室开启了约课，课程旁边会有「预约」按钮，
填**学员全名 + 手机号**（备注选填）即可，不用注册账号、不用设密码。

- 提交后页面会**如实告诉你这节课还剩几个位置、已经有几份申请在等确认**;
- **申请不等于占位**：工作室确认后才算数，确认后会联系你;
- 不小心点了两次没关系——同一个号码对同一节课重复提交，页面会说
  「已经收到了，请等待」，不会变成两条申请;
- 已经满员的课也可以提交，相当于**候补**。

## 二、在线报名 / 预约体验

两个入口，填的内容一样：官网导航的「预约体验」按钮，或独立报名页
`/<工作室网址标识>/register`（工作室可能直接把这个链接发给你）。

1. 填写表单：姓（选填）、**名字（必填）**、**手机号（必填）**、邮箱（选填）、
   报名对象（我自己/孩子/青少年/家庭·多人）、工作室自定义的问题（最多 8 个，
   带 `*` 的必填）、留言（选填）。
2. 勾选**隐私声明同意**：「我同意信息仅用于教学联系与管理」。可点「阅读
   隐私说明 →」查看全文，页面底部会显示当前的声明版本号（如
   「本说明版本：2026-07-12」），你的同意会记录到这个版本。不勾选无法提交。
3. **作品展示授权（选填）**：如果你愿意让工作室在官网或招生材料中展示学员
   作品，可勾选此项，并填写「授权人姓名」和「与学员关系」（本人/家长·监护人/
   其他授权监护人）。**此授权可随时联系工作室撤回**；不勾选不影响报名。
4. 点「提交预约」（报名页上是「提交报名」）。成功后会看到确认页：
   「已提交，老师会在 24 小时内与您联系」。之后请留意电话、短信或邮件。
5. 提交失败时：
   - 表单会用红框和文字提示第一个漏填的必填项;
   - 「连接不上工作室……你填的内容都还在，重新点一次提交即可」——网络
     问题，内容不会丢，重试即可;
   - 反复失败可直接致电工作室，由工作人员手动登记。

提交后你的申请进入工作室的「待审核」列表，由工作人员联系你、安排试听并
建档——报名页不会立刻给你访问码。

## 三、学员专区：访问码自助查询

### 访问码从哪里来

访问码是**工作室发放的 6 位数字**，通常在第一次上课后由工作室交给你——
可以问任课老师，或通过官网底部的联系方式索取。它不是短信验证码，请妥善
保存；忘记了可以请工作室**重新发放**（旧码会同时失效）。

### 如何查询

1. 点官网导航的「学员专区」（或首屏的「学员登录 →」、作品墙下方的
   「登录查看我的作品集 →」）。
2. 填写三项信息：
   - **学员姓名**——必须与报名时登记的完全一致;
   - **手机号**——报名时登记的号码（当初留的是家长手机号就填家长的）;
   - **6 位访问码**（输入时显示为圆点）。
3. 点「查询」。验证通过后可以看到：
   - **剩余课时**大数字。余额偏低时会有提示：「课时即将用完，欢迎续课」；
     用完或透支会提示联系老师结算/续课;
   - **下次课**：日期 · 时间 · 课程;
   - **上课记录**：最近的签到历史（日期 + 课程）;
   - **我的作品集**：老师为学员上传的作品图片（标题/日期）。
4. 查完点「退出专区 / 重新查询」即可退出。查询会话 **1 小时后自动过期**，
   过期后提示「登录已失效，请重新验证」，重新填三项信息即可。

### 查询失败怎么办

- 「这三项信息没有匹配到学员记录」——姓名和手机号必须与工作室登记的完全
  一致；如果报名时用的是家长手机号，请改用那个号码；仍不行请联系工作室
  重新发放访问码。
- 「尝试次数过多，请在 N 分钟后重试」——连续输错会临时锁定，等提示的
  时间过后再试。
- 「连接不上工作室，可能是网络中断」——检查网络后重新点查询。

## 四、隐私与照片

- 报名信息仅用于课程联系与学员管理（详见官网「隐私说明」页）。
- 学员作品与照片**默认私密**，只有通过姓名 + 手机号 + 访问码验证后才能在
  学员专区看到自己的作品。
- 只有在你签署了公开授权（报名时勾选或之后补签）的情况下，作品才可能出现
  在公开的作品墙上；撤回授权后所有作品立即回到私密状态。
- 需要更正信息、删除资料或撤回授权，直接联系工作室即可。
- **你的授权与撤回记录永久保存。** 系统会定期清理旧的日志类数据（例如查询
  会话 30 天后清除），但作品公开授权的同意与撤回**明确不在清理范围内**——
  那是"你当初同意过什么、什么时候撤回的"的凭证，只增不改、永不删除。

## 常见问题（FAQ）

**Q1：我需要注册账号或设置密码吗？**
不需要。浏览和报名完全开放；查询个人记录用「姓名 + 手机号 + 访问码」。

**Q2：还没有访问码怎么办？**
访问码由工作室在第一次课后发放。问任课老师，或用官网底部的联系方式向
工作室索取。

**Q3：访问码忘了 / 怀疑被别人知道了？**
联系工作室重新发放。新码生成的同时旧码立即作废，已登录的查询会话也会
被踢出。

**Q4：为什么显示的是「课时」而不是「还能上几节课」？**
一节课可能消耗不止 1 个课时（例如长课），所以专区显示的是课时余额。
具体一节课扣多少，以工作室的课程安排为准。

**Q5：能在学员专区直接续费吗？**
不能，专区只做查询。续课请联系工作室办理，到店或转账后由工作人员入账。

**Q6：切换成英文后课程名怎么还是中文？**
课程名、作品标题是工作室录入的运营数据，按原文显示、不做翻译；只有界面
文字和板块标题会切换语言。

**Q7：一家有两个孩子怎么查？**
每个学员有自己的访问码。分别用各自的「学员姓名 + 登记手机号 + 访问码」
查询即可（手机号可以是同一个家长号码）。

**Q8：提交报名后多久有回复？**
页面承诺 24 小时内联系。超时未收到请直接致电或邮件联系工作室。

**Q9：家长能用邮箱密码登录吗？**
不能。工作室的管理系统只对员工开放，家长账号登录会被拒绝并提示
「家庭自助登录暂未开放，请联系工作室」。家庭自助查询就是为你准备的
「学员专区」——姓名 + 手机号 + 访问码，无需注册、无需密码。

**Q10：工作室发来一个「作品分享链接」，和学员专区有什么区别？**
分享链接是工作室主动生成的临时展示页，点开即可看作品、不用输任何信息，
适合转发给亲友；它有有效期（最长 90 天），到期或被工作室撤销后就打不
开了，需要时请工作室重新生成。学员专区则是长期入口，凭访问码随时查询
课时、上课记录和作品。

## 权限边界表（学员/家长）

| 操作 | 可以吗 | 说明 |
|---|---|---|
| 浏览官网课程 / 作品墙 / FAQ | ✅ | 无需登录 |
| 在线报名 / 预约体验 | ✅ | 需勾选隐私声明同意 |
| 查询课时余额 / 上课记录 / 下次课 / 作品 | ✅ | 姓名 + 手机号 + 访问码 |
| 修改自己的档案信息 | ❌ | 联系工作室由工作人员修改 |
| 在线充值 / 续费 | ❌ | 联系工作室办理 |
| 登录运营 CMS | ❌ | 家长身份会被拒绝：「家庭自助登录暂未开放，请联系工作室」 |
| 授权 / 撤回作品公开展示 | ✅ | 报名时勾选，或随时联系工作室变更 |
