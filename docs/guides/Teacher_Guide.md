# CMS 教师手册 · Teacher（任课老师）

> 适用版本：PWE Studio v8.7.0 · 界面：运营 CMS（`/<工作室网址标识>/cms`）
> 其他角色手册见 [手册总览](README.md)

## 角色定位

Teacher 账号面向任课老师：你负责**上课当天的事**——看当日名单、给学员签到、
撤销签错的签到、上传和整理学员作品。你可以查看学员档案和操作日志，但看不到
任何财务信息（营收、充值、退款、经营统计），也不能修改学员档案、审批报名或
办理充值。

## 快速上手

1. 打开 `https://<你的域名>/<工作室网址标识>/cms`，输入 Owner 发给你的
   「管理员邮箱」和临时密码，点「进入系统 →」。
2. 第一次登录后，点侧栏齿轮打开「系统设置」，在「修改登录密码」里把临时
   密码换成自己的密码（新密码至少 8 位）。
3. 你的导航里只有四个标签页：**工作台 · 每日排课 · 学员档案 · 操作日志**
   （v7.4.0 起 Teacher 拥有「每日排课」标签页，与后端签到权限对齐）。

## 一、工作台

- **今日指挥台**：应到 / 已签到 / 待审核 / 低课时四个数字。你能点的快捷
  按钮是「今日排课」；「新建学员」「审核报名」「充值结算」不会出现在你的
  界面上。
- **经营真账**折叠区对你只显示上课人次（已上课总次数、本月次数）；已赚收入、
  预收负债、净现金收入等财务字段不会下发到你的账号——这是后端按角色投影的，
  不只是界面上藏起来。

## 二、每日排课与签到（你的主战场）

1. 点「每日排课」，顶部选择日期（默认今天）。
2. **每周课表**区块能看到固定班次（周几、时间、人数），但「新增班次」
   「编辑」「删除」按钮不会出现——班次管理需要 Owner/Manager 权限。
3. 当日名单里为到场学员**签到**：每次签到自动扣课时并记入账本。余额为 0
   的学员签到时系统会拦截提示。
4. **签错了**：可撤销当日签到，课时退回，账本留下冲正记录。
5. **生日横幅**：近 14 天生日的学员会显示在排课页顶部，点一下即可复制
   生日祝福话术发给家长。

## 三、学员档案（可看、可传作品，不可改资料）

- 可以搜索、筛选、打开任何学员的档案，查看联系方式、课时余额、上课记录。
- 「➕ 新建」按钮、编辑资料、归档、CSV 导出对你不可见（需要 students:write，
  Teacher 没有）。
- **作品集是你的职责**：在学员档案里可以上传作品照片（标题、日期、说明
  选填）、编辑作品信息、删除作品（portfolio:write）。格式限 JPEG / PNG /
  WebP，**单张最大 3000 万像素**（约 6000×5000），超限会明确拒绝。
  （v8.2.6 之前生产环境的所有图片上传都会失败，那是产品缺陷，已修复。）
  - 作品标题按录入原样显示，不随界面语言翻译（产品决策）。
  - 「公开到门户作品墙」取决于该学员是否有有效的公开授权；没有授权时作品
    只能保持私人可见。
  - 生成对外**分享链接**不在你的权限里（portfolio:share 仅 Owner/Manager，
    有效期 1–90 天）；不过**撤销**已有的分享链接你可以做（撤销属于作品
    维护权限）——发现链接不该继续存在时可以直接撤掉，再告知店长。
- 学员专区**访问码**的生成/更换在档案页由有权限的同事操作；家长问起访问码
  时，请转给店长处理，或按门户提示引导家长联系前台。

## 四、操作日志

「操作日志」标签页可以查看全部操作留痕（签到、撤销等都在里面），支持按
学员、类型、日期筛选。「导出 CSV」按钮仅 Owner/Manager 可见。

v8.2.3 起这一页覆盖 30 类操作并且都有中文名称——你的签到、撤销、作品上传
与修改都会以「签到」「上传作品」「修改作品」这样的中文出现，带日期与
学员名，不再是一串机器编号。审计记录保留两年。

## 常见问题（FAQ）

**Q1：为什么我看不到「充值结算」「待审核」「经营统计」？**
这些标签页需要财务或报名权限（credits:write / registrations:write /
analytics:read），Teacher 角色没有。需要办理充值或审批报名时请交给前台
或店长。

**Q2：家长问「还剩几节课」，我在哪里看？**
打开「学员档案」搜索该学员，档案里能看到课时余额。也可以引导家长用访问码
在门户「学员专区」自助查询。

**Q3：我能建新学员吗？**
不能，「新建学员」需要 students:write 权限。**此操作需要 Front Desk /
Manager / Owner 权限。**

**Q4：签到扣错课时了怎么办？**
在当日名单撤销该次签到即可，课时自动退回。如果发现的是历史某天的错账，
请交给 Manager/Owner 处理。

**Q5：作品传上去了但门户作品墙看不到？**
门户作品墙只展示「已公开」的作品，公开的前提是该学员有有效的公开授权
（家长在报名表勾选或后来补签）。没有授权时作品只在学员自己的专区可见。

**Q6：登录不上系统怎么办？**
分三种提示：邮箱或密码不正确 → 找 Owner 重置密码；「该账号没有有效的
工作人员身份，请联系管理员」→ 你的成员身份被停用，找 Owner 启用；
「家庭自助登录暂未开放」→ 你登录的是家长账号，不是员工账号。

**Q7：家长问能不能自己登录看孩子的课时和作品？**
家长不能登录 CMS。家庭自助查询走官网「学员专区」：姓名 + 手机号 +
6 位访问码。访问码由前台/店长在学员档案里生成发放（你没有这个权限），
请把家长转给前台。

**Q8：界面语言怎么切换？**
右上角「中文 / English」，整个浏览器记忆一份、默认中文。学员姓名、
课程名、作品标题等运营数据按录入原样显示，不随语言切换翻译。

## 权限边界表（Teacher）

| 功能 | Teacher | 说明 |
|---|---|---|
| 工作台（无财务字段） | ✅ | 财务数据后端不下发 |
| 每日排课 / 签到 / 撤销签到 | ✅ | attendance:write（v7.4.0 起有 roster 标签页） |
| 每周课表班次的增删改 | ❌ | 需要 Owner/Manager 权限 |
| 学员档案查看 | ✅ | students:read |
| 学员档案新建 / 编辑 / 归档 | ❌ | 需要 students:write（Front Desk/Manager/Owner） |
| 作品集上传 / 编辑 / 删除 | ✅ | portfolio:write |
| 作品分享链接创建 | ❌ | portfolio:share，仅 Owner/Manager |
| 作品分享链接撤销 | ✅ | 撤销走 portfolio:write |
| 充值 / 退款 | ❌ | 需要 credits:write / credits:refund |
| 报名审批（待审核） | ❌ | 需要 registrations:write |
| 经营统计 / 财务报表 | ❌ | 需要 analytics:read |
| 操作日志查看 | ✅ | 导出 CSV 仅 Owner/Manager |
| 系统设置：改自己的密码、退出登录 | ✅ | — |
| 团队管理 / 套餐管理 | ❌ | 仅 Owner（/Manager 可见部分） |
