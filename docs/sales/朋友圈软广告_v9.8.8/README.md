# PWE Studio 朋友圈软广告

v9.8.8 · 1080 × 1080 · 9 张 PNG

这是面向潜在客户的朋友圈软广告素材包，包含：

- `01-cover.png` 至 `09-cta.png`：9 张可直接发布的正方形图片
- `contact-sheet.png`：九宫格预览
- `发布文案.md`：主文案、短版文案、逐图配文与发布建议
- `index.html`：可编辑的 HTML 画布，使用 `#card-01` 至 `#card-09` 切换卡片

## 本地查看

直接打开 `index.html`，或在浏览器地址后追加 `#card-01` 到 `#card-09`。

HTML 使用仓库内真实的 PWE Studio 品牌 logo 与产品截图，修改文字或布局后可重新截图导出。
