## 异议处理

**「数据在哪里?安全吗?」**
- 每家机构的数据严格隔离,跨店访问必须失败——每次发版跑 **201 项租户隔离自动化测试**,全绿才允许上线。
- 平台方自己也被管着:平台人员要看机构数据,必须开启支持模式——填写原因、写入审计日志、页面横幅明示。我们不「悄悄看」任何一家的数据。
- 未成年人照片有同意链:公开作品必须记录监护人同意,同意/撤回是只增不改的事件记录,撤回立即下线;对外分享链接强制 1–90 天到期、可随时撤销。
- (若追问部署细节)目前为试点阶段托管部署,按需在线;正式扩容路线已有部署文档,可约技术沟通。

**「能自定义吗?会不会所有店长得都一样?」**
- 能,而且不用写代码:Logo、配色、双语文案、报名问题全部可配;8 套行业模板一键套用、可一键撤销;8 套专业主题(15 个明暗变体)全部通过 WCAG 对比度校验。
- 改动走「草稿 → 预览 → 发布 → 版本回滚」,改错了随时回到上一版,不影响线上。
- 边界也要说清楚:我们不做每客户定制开发——这是系统能长期便宜、稳定、可维护的原因。

**「我们现在都在 Excel 里,怎么迁过来?」**
- 迁移是 Setup 服务的一部分,不用你动手:你给学员名单和课时余额,我们导入并核对。
- 只迁核心数据(学员档案 + 课时余额),历史流水不搬——上线当天从干净的账本开始,余额以双方核对数为准。
- 上线前会用你的真实数据做一轮预览确认,团队按角色培训(前台收费、老师签到、店长看账)。

**「为什么还要收 Setup fee?」**
- 这不是软件费,是**交付服务费**:品牌配置、数据迁移、按角色培训、上线首周伴随支持,都是实打实的人力。
- 一次性 AUD 299–999,按机构规模和迁移量一次报价,不藏后续费用;交付完成后你拿到的是「开门即用」的系统,不是一个空账号。
- 也正因为有 Setup,我们敢承诺上线质量——比「自己摸索一个月」便宜得多。

## 提醒

- 全程用澳元(AUD)报价,不要换算。
- Setup 区间 299–999 已拍板,不打折说 799 以下的旧口径。
- 不承诺尚未上线的功能(在线支付、家长登录账号等);家长侧目前是访问码自助区。
