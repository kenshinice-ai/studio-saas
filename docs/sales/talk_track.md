配套 `PWE_Studio_销售介绍.pptx`，目标时长 15–20 分钟 + 答疑。
听众是画室主理人、音乐老师、舞蹈工作室创始人——手艺人，不是行政。

核心叙事：**一个创造力的起点 → 把行政退到幕后 → 让成长、上升和
可能性重新站到台前。**

## 品牌开场

PWE Studio 的四角星，是创造力的起点。三根向上舒展的羽片，分别
代表成长、上升和可能性。它不是把平台放在客户前面，而是提醒我们：
系统只负责托住运营，让每一家工作室用自己的名字、作品和方法继续
向上。

## 异议处理

**「会不会所有工作室看起来都一样？」**

- 不会。客户 Logo、配色、双语文案、报名问题和内容都可以配置。
- Studio Admin、CMS、Portal 和 Register 均以租户身份为主；没有上传
  Logo 时显示工作室名称，不用平台 Logo 代替。
- 页面只在页脚保留低调的 `Powered by Paradise Production` 文本。

**「数据在哪里？安全吗？」**

- 每家机构的数据严格隔离，跨店访问必须失败。
- 平台人员进入机构数据需要支持模式、填写原因并写入审计日志。
- 未成年人照片使用可撤回的同意链；分享链接强制到期。

**「我们现在都在 Excel 里，怎么迁过来？」**

- 迁移是 Setup 服务的一部分：导入学员档案和已核对的课时余额。
- 上线前使用真实数据预览确认，并按角色完成团队培训。

**「为什么还要收 Setup fee？」**

- 这是品牌配置、数据迁移、角色培训和上线支持的交付服务费。
- 一次性 AUD 299–999，按规模和迁移量报价。

## 演示纪律

- 产品名称只写 **PWE Studio**；SaaS / Edition 只描述交付模式。
- 四角星与三根羽片的含义不得改写。
- 客户界面永远让客户品牌占主位。
- 使用 Navy `#0E1729`、Amber `#F5B335`、Warm Paper `#F7F5F2`。
- 全程用澳元（AUD），不承诺尚未上线的功能。
