# 独立版 · 收费结构骨架（待拍板）

> 提案文档。所有数字均为**建议区间**，最终定价等确认。
> 参照锚点：SaaS 版订阅 AUD 49/99/199 月 + setup fee AUD 299–999（已拍板）。

## 1. 一次性交付费（setup + 迁移）

| 档 | 内容 | 建议区间 (AUD) |
|---|---|---|
| **基础交付** | 服务器部署 + 域名/TLS + 品牌配置（行业预设起步）+ 全新开店 | 1,500 – 2,500 |
| **标准交付** | 基础 + 学员/课时/套餐数据迁移（≤500 学员）+ 员工账号与角色 + 2 小时远程培训 | 2,500 – 4,000 |
| **完整交付** | 标准 + 从 SaaS 平台整租户迁出（含媒体/同意链证据）或复杂旧系统清洗 + 上线陪跑 2 周 | 4,000 – 6,500 |

> 定价逻辑：独立版交付的是**数据与运维主权**，一次性费用应显著高于
> SaaS setup fee（299–999），并覆盖实施工程师 1–3 天工时 + 交付风险。
> 服务器与域名成本实报实销，不含在上表。

## 2. 后期维护协议（年付，独立选购）

| 档 | 内容 | 建议区间 (AUD/年) |
|---|---|---|
| **保底** | 安全补丁代装（重大 CVE）+ 每季恢复演练 + 邮件支持（48h） | 600 – 900 |
| **标准** | 保底 + 每年 2 次版本升级 + 备份异地副本代管 + 4h 响应 | 1,200 – 1,800 |
| **托管** | 标准 + 服务器代管（含监控告警）+ 小改需求包（年 8h） | 2,400 – 3,600 |

无维护协议的客户：交付版本永久可用（买断性质），后续任何服务按
单次报价（起步费建议 AUD 300/次）。

## 3. 边界条款（合同要点，防扯皮）

1. **交付即断链**：平台无技术访问能力（见 DEPLOYMENT.md §5），
   之后一切服务需客户授权并计费。
2. **数据主权**：数据库、媒体、备份全部在客户实例；我们不留副本
   （交付验收对账单除外，保留 90 天后销毁）。
3. **升级不承诺功能**：维护协议内的版本升级 = 当时最新稳定版，
   不承诺特定新功能时间表。
4. **二次分发禁止**：源码包按交付协议仅限该客户单实例使用
   （内核 Apache-2.0，品牌资产与交付脚本另行约束）。
5. **署名（待拍板）**：默认保留页脚小字署名；去署名作为付费选项
   （建议 +AUD 500 一次性）。

## 4. 目标客户画像（销售侧参考）

- 对数据主权敏感（不接受学员数据在第三方平台）的机构
- 已有稳定 IT 供应商/内网环境的中大型工作室
- SaaS 版用满一年后想「买断落地」的成熟客户（路径 1 迁移）
- 预算特征：能接受数千澳元一次性投入换取长期零订阅
